选择授权方式

方式一适合想用「网页弹窗一键授权」的用户：需先注册自己的 Azure 应用（约 5 分钟）， 之后每个邮箱授权都是一键完成。不想注册？直接用下方「方式二」即可。

1
注册 Azure 应用

进入 Azure 门户 → 应用注册，点击「新注册」。

  • 名称：自定义（如 OutlookEmailPlus）
  • 受支持的账户类型：选择「Accounts in any organizational directory and personal Microsoft accounts」（任意目录 + 个人账号）
  • 不要选「仅个人 Microsoft accounts」，否则会触发 AADSTS9002331 错误
2
配置平台与重定向 URI

进入应用 →「身份验证」→「添加平台」→ 选择「移动和桌面应用程序」（公共客户端，无需 Client Secret）；在「自定义重定向 URI」填入本服务回调地址：

  • …/token-tool/callback
  • 若选「Web」平台也可以，但必须配合第 3 步开启公共客户端流
3
开启公共客户端流

同页「身份验证」→ 页面底部「高级设置」→ 将「允许公共客户端流」设为「是」。

这一步最容易遗漏！缺失会导致 unauthorized_client 错误。

4
配置 API 权限

进入应用 →「API 权限」→「添加权限」→ 选择「Microsoft Graph」→「委托的权限」，添加以下权限：

  • offline_access（必须，用于获取 refresh_token）
  • Mail.ReadWrite（读取 + 删除邮件，本系统主链路）
  • User.Read（读取用户信息，可选）

💡 若只用 IMAP 通道，可在上方「高级」中切换 IMAP 预设，则此处无需 Graph 权限。

5
填入 Client ID 并一键授权

进入应用「概述」页，复制「应用程序（客户端）ID」，填入上方 OAuth 配置的 Client ID；Redirect URI 改为本服务回调地址（…/token-tool/callback）。

然后点下方「一键授权」→ 弹窗打开微软登录页 → 登录 Outlook / Hotmail 邮箱并同意 → 授权成功自动回传，自动换取 Token，无需复制粘贴。

勾选后每次授权都会弹出同意页（prompt=consent），适合同一 Client ID 授权多个邮箱时确保权限明确。 当前为 Thunderbird 默认 ID（回调 https://localhost），不支持弹窗回传；请按上方 1-5 步注册自建应用，或切到「方式二」免注册直接授权。
1
打开授权页并登录

点下方「获取授权链接」→「打开链接」进入 Microsoft 登录页，用你的 Outlook / Hotmail 邮箱登录并同意授权。

  • Client ID 已默认填入 Thunderbird 公开 ID（9e5f94bc-e8a4-4e73-b8be-63364c29d753），无需注册任何应用
  • Redirect URI 固定为 https://localhost（Thunderbird 已登记的回调地址）
2
复制跳转后的完整网址

授权成功后浏览器跳转到 https://localhost?code=...，页面显示“无法访问此网站”是正常现象。

复制地址栏中的完整 URL（从 https://localhost?code= 开始），粘贴到下方「换取 Token」区域。

3
换取 Token 并写入账号

点「换取 Token」自动完成授权码交换，拿到 refresh_token 后即可「写入到账号」。

  • 默认 scope：Mail.ReadWrite offline_access（Graph 读取 + 删除邮件），与本系统主链路一致
  • 若用 IMAP 通道，可在上方「高级」中切换 IMAP 预设
适用于大多数场景，推荐首选
